## 3. Editor 辅助入口与进度隔离

新增唯一功能脚本：`Assets/Editor/DDayPVRecording.cs`，同时有 `#if UNITY_EDITOR`。不挂组件、不写场景、不修改任何正式脚本/配置；类型位于 Editor 程序集，不进入 Player 构建。

1. 停止 Play，打开并保存原 `TodayWhereToSit` 场景。若 Play Mode Start Scene 指向其他场景，先在编辑器中恢复原场景。
2. 菜单 **D-DAY > PV Recording > Open Recording Assistant**。
3. 点 **开始新的隔离录制会话（1080p）**。每次生成唯一目录 `Docs/PVRecording/Sessions/<时间_UUID>/`，进入 Play 后停在原主菜单。
4. 用原“开始游戏”进入 Day 1。它重置的是本次独立 `AutoSave.json`，不是玩家存档；录制操作会正常自动保存，手动槽也保存在同一独立目录。
5. 原教程可正常完成；想拍无遮挡办公室时，使用游戏现有“跳过教程”。这只影响本次独立进度。
6. 在一周目 Day 1–5 排座阶段关闭弹窗、停止拖拽，点 **保存当前排座阶段检查点**。保存初始布局、Day 1 工作前、Day 2、Day 3、Day 5 等实际到达状态，文件名带 Day 和唯一 ID。
7. 点 **恢复已实际到达的检查点**，选择 `Sessions` 内本工具生成的 `Checkpoint_Day*.json`。只允许主菜单或无弹窗排座阶段恢复，走正式 `ContinueGame()`。跨会话也可选择旧录制检查点。不能加载正式存档，不能直接指定尚未到达的日期。
8. 重拍 Day 1 结尾：正常演出到 Day 2 后恢复“Day 1 工作前”检查点，再按原“开始工作”；不强制切换 Death 或发放物品。
9. 点 **结束会话**或正常停止 Play。工具恢复 `DDAY_SAVE_OVERRIDE`、四项原 PlayerPrefs 设置及原 Game 视图分辨率选择。已有检查点保留，方便以后重拍；工具不删除素材。

若有其他自动验收或非空 `DDAY_SAVE_OVERRIDE`，助手拒绝开始以免会话冲突。录制会话中不要同时运行其他验收工具。正常退出会自动清理会话环境；若编辑器崩溃或被强制结束，重新打开原工程后只从新的隔离会话开始，旧录制 JSON 仍可从助手加载。

自检入口 **D-DAY > PV Recording > Verify Isolated Session**：只做独立验证，会进入并退出 Play，不录视频。结果在 `Docs/PVRecording/Verification.txt`；每个会话有 `SessionResult.txt`，核对正式自动/手动 JSON 及其备份的哈希是否不变。

## 4. 录制画面与声音设置

首选原 Unity Game 视图配合已有 OBS。助手只设 Game 渲染尺寸，不是录屏软件。

- Game 视图固定 **1920×1080**。辅助窗口放在 Game 区域之外；关闭 Stats、Gizmos 和调试座位标记。录制前结束所有弹窗提示，静置至少 3 秒。
- OBS 使用窗口捕获或显示捕获，裁出 Game 内容区，不包含工具栏、Hierarchy、Inspector、鼠标提示和助手。基础画布/输出均 1920×1080，帧率 30fps；机器稳定时可统一改为 60fps。编码用现有硬件 H.264，高质量设置，48kHz 立体声，关闭麦克风。参数为本方案建议，应先按机器测试。
- **Game 渲染 1080p 不代表屏幕上显示了 1080p。** Game 缩放小于 1 时，OBS 会录到缩小后的像素，放大不能还原细节。需要把 Game 最大化或浮动到足够大的屏幕，使完整内容 1:1 显示；空间不足则整套统一退到 1280×720 / 30fps，并在交接标注源分辨率，不伪称原生 1080p。
- 捕获光标用于排座、点击；纯主菜单/办公室空镜可把光标移出内容区。建议都保留原 BGM/SFX，剪辑阶段按需要降音乐；无需为音频拆轨改动游戏。
- 若 OBS 支持录 MKV，先录 MKV 再使用自身 Remux 转 MP4；保留原文件。录制快捷键应避开游戏推进键，先录 10 秒拖拽/台词/雷声测试，确认无黑屏、丢帧、裁切与声音延迟再正式录。OBS 实际采集链本轮未测试，也未自动安装 OBS。
- Unity Recorder 未安装，本轮不使用。如以后另行授权安装，应优先录 **Game View**（当前同时有 UGUI 和 IMGUI），先验证 UI、音频与实际尺寸；单独 Camera 输入不作为此 UI 游戏的默认方案。

参考：[OBS 官方开始指南](https://obsproject.com/kb/quick-start-guide)，[Unity Movie Recorder 官方输入/输出说明](https://docs.unity3d.com/Packages/com.unity.recorder@5.1/manual/RecorderMovie.html)。

### 顺路拍摄方法

物理录制顺序就是 01→12，再返回菜单拍 13。同一阶段先拍空镜再拍操作，再拍对话，减少重置。备用早期关系在 Day 1 录；若准备动作造成短提示，先等提示消失。

Day 1 初始布局可用以下 **人工拖拽**路线完成现有规则：ORIN 从 B2 → A1（与狐狸交换）；ECHO 从 A3 → A2；CASSIA 从 B4 → B1（与棕熊交换）；THANE 从交换后的 B4 → A3。SISY 不动。最终 A1 ORIN、A2 ECHO、A3 THANE、A4 METIS、B1 CASSIA、B2 NARCIS、B3 SISY、B4 空。助手不自动解题。

任务完成后点击“开始工作”。Day 1 只有九月工作汇报任务，可按原流程选择 SISY 作为这次原剧情演出负责人；这不是额外剧情触发器。Day 2 继续分配遗留工作并正常完成固定 ORIN 了解情况；Day 3 再做排座与三个真实工作分配。要录 Day 5，Day 3/4 按原要求完成和正常推进即可。
